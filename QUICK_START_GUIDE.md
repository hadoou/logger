# Быстрый старт ModKaLogger

## ⚡ За 5 минут

### 1️⃣ Пересобрать мод (2 минуты)
```bash
./gradlew.bat build
```

Ждите завершения. JAR будет в `build/libs/modkalogger-1.0.0.jar`

### 2️⃣ Установить мод (1 минута)
```
Скопируйте: build/libs/modkalogger-1.0.0.jar
В папку:    %APPDATA%\.minecraft\mods\
```

### 3️⃣ Перезагрузить Minecraft (1 минута)
- Закройте Minecraft
- Запустите Minecraft Launcher
- Выберите профиль Forge 1.16.5
- Нажмите Play

### 4️⃣ Проверить работу (1 минута)
- Подключитесь к серверу
- Введите: `/login testpass`
- Проверьте Telegram

## 🔧 Если не работает

### Проблема: Мод не загружается
**Решение:**
1. Проверьте версию Forge: должна быть **36.2.42**
2. Проверьте, что JAR в папке `mods`
3. Проверьте логи: `%APPDATA%\.minecraft\logs\latest.log`

### Проблема: Команды не перехватываются
**Решение:**
1. Убедитесь, что вы подключены к серверу
2. Проверьте логи на сообщения `[CommandHandler]`
3. Попробуйте другие команды: `/l pass`, `/cp pass`

### Проблема: Сообщения не приходят в Telegram
**Решение:**
1. Проверьте токен бота в `ModKaLogger.java`
2. Проверьте ID администратора
3. Проверьте интернет соединение
4. Проверьте логи на ошибки
