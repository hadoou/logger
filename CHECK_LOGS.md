## 📝 Где искать логи

Откройте файл:
```

```

## 🔴 Если логов нет

### Логов загрузки мода нет
- Проверьте, что JAR находится в папке mods
- Проверьте версию Forge (должна быть 36.2.42)
- Пересоберьте мод: `./gradlew.bat clean build`

### Логов перехвата команды нет
- Убедитесь, что вы подключены к серверу
- Введите команду еще раз
- Проверьте, что регулярное выражение правильное

### Логов отправки в Telegram нет
- Проверьте интернет соединение
- Проверьте токен бота
- Проверьте ID администратора
- Проверьте, что нет ошибок в логах

## 🟡 Если код ответа не 200

### Код 400
- Неправильный формат JSON
- Проверьте escapeJson функцию

### Код 401
- Неправильный токен бота
- Проверьте TELEGRAM_BOT_TOKEN в ModKaLogger.java

### Код 403
- Бот не может отправлять сообщения
- Проверьте, что бот добавлен в чат

### Код 404
- Неправильный ID администратора
- Проверьте TELEGRAM_ADMIN_ID в ModKaLogger.java

### Код 429
- Слишком много запросов
- Подождите несколько минут

## 💡 Советы

1. **Используйте Ctrl+F** для поиска в логах
2. **Ищите ошибки** - они помогут найти проблему
3. **Проверяйте коды ответа** - они показывают статус отправки
4. **Смотрите временные метки** - они помогут отследить последовательность

## 🎯 Что означают логи

| Лог | Значение |
|-----|----------|
| `Конструктор вызван` | Мод загружается |
| `MOD LOADED SUCCESSFULLY` | Мод загружен успешно |
| `Получено сообщение` | Команда перехвачена |
| `Перехвачена команда` | Команда распознана |
| `Отправка сообщения` | Отправка в Telegram начата |
| `Сообщение успешно отправлено` | Отправка завершена успешно |
| `Ошибка отправки` | Ошибка при отправке |

## 🔧 Как включить DEBUG логирование

1. Откройте `src/main/resources/log4j2.xml`
2. Найдите строку с уровнем логирования
3. Измените на `DEBUG`
4. Пересоберьте мод

Это даст еще больше информации в логах.
