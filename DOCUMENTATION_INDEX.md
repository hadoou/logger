## 📞 Поддержка

Если вы не нашли ответ на свой вопрос:
1. Проверьте **DEBUGGING_GUIDE.md**
2. Проверьте логи: `%APPDATA%\.minecraft\logs\latest.log`
3. Прочитайте **HOW_IT_WORKS.md** для понимания
4. Пересоберьте мод: `./gradlew.bat clean build`
